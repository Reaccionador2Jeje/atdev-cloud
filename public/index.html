Developer tools

API Reference

Endpoints disponibles en esta versión de AtDev Cloud.

BASE URL

Los endpoints privados requieren Authorization: Bearer TU_TOKEN.

Autenticación

POST/v1/auth/register

Crear una cuenta. Body: { "email": "...", "password": "..." }

POST/v1/auth/login

Iniciar sesión y obtener un token bearer.

GET/v1/auth/me

Consultar la cuenta autenticada.

Proyectos

GET/v1/projects

Listar los proyectos de la cuenta.

POST/v1/projects

Crear proyecto. Body: { "name": "Mi app", "slug": "mi-app", "description": "..." }

GET/v1/projects/:slug

Obtener un proyecto.

PATCH/v1/projects/:slug

Actualizar nombre o descripción.

DELETE/v1/projects/:slug

Eliminar el proyecto y sus registros asociados.

Registros JSON

GET/v1/projects/:project/records/:collection

Listar registros de una colección.

POST/v1/projects/:project/records/:collection

Crear un registro JSON.

GET/v1/projects/:project/records/:collection/:id

Obtener un registro.

PATCH/v1/projects/:project/records/:collection/:id

Actualizar un registro.

DELETE/v1/projects/:project/records/:collection/:id

Eliminar un registro.

Database & Health

GET/health

Estado público del servicio.

GET/v1/database/status

Comprobar conexión con AtDev DB.

POST/v1/database/query

Ejecutar SQL en la base de un proyecto.

Ejemplo JavaScript

const response = await fetch("https://atdev-cloud.cristopheriguaran-7.workers.dev/v1/projects", {
  headers: { Authorization: "Bearer TU_TOKEN" }
});
const data = await response.json();
console.log(data.projects);
